# 前端 playground

需要 [pnpm](https://pnpm.io/)（`corepack enable` 即可）。Java 服务先在 8080 启动。

```bash
pnpm install
pnpm dev
```

打开 http://localhost:5173 。详情见仓库根目录 README。

## 宣传页

```bash
pnpm dev
```

- Playground：http://localhost:5173/
- 基础闭环宣传页：http://localhost:5173/promo.html

构建后独立产物：`dist/promo.html`。
